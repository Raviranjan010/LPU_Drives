Key Responsibilities:
1) Coding Question Creation: 
** Create high-quality coding questions across Data Structures and Algorithms, C, C++, Python, Java, SQL, JavaScript, and related programming topics.
2) Question Review and Validation: 
** Review coding questions for correctness, clarity, ambiguity, difficulty level, constraints, input/output formats, and alignment with assessment objectives.
3) Test Case Design: 
** Develop and validate sample, hidden, edge, and corner test cases to ensure that questions evaluate the intended logic and handle all valid scenarios.
4) Solution Development: 
** Write accurate reference solutions, explanations, and time and space complexity analysis for coding questions.
5) Question Bank Management: 
** Organize, maintain, update, and improve coding question banks to ensure content quality, consistency, usability, and relevance.
6) Classification and Tagging:
**  Classify and tag questions based on topic, sub-topic, programming language, difficulty level, skill area, assessment type, expected time, and use case.
7) Assessment Design: 
** Create customized coding assessments and question papers from existing question banks based on client requirements such as role, difficulty, duration, technology stack, and topic coverage.
8) Content Quality Assurance: 
** Identify and fix issues in existing questions, solutions, test cases, and metadata to maintain technical accuracy and assessment reliability.
9) Client Requirement Mapping: 
** Collaborate with internal sales, engagement, and delivery teams to understand client requirements and design suitable coding assessments.
10) Content Research:
**  Research coding platforms, industry hiring trends, programming concepts, and assessment patterns to improve the quality and relevance of question banks.
11)Platform Utilization: 
** Understand and effectively use the internal assessment or question bank platform to upload, tag, manage, and generate coding assessments.
12) Continuous Improvement: 
** Incorporate feedback from clients, reviewers, candidates, and internal teams to improve coding questions, assessment structure, and question bank quality.
