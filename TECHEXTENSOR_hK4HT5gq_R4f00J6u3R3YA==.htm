Job Profile Details:

What Will You Do:
Real systems, real users, from your first sprint
Build & Ship
** Write Python services, agent workflows, and UI that go into production, not into a demo folder. 

Ground the Model
** Work on retrieval, prompts, and tool design so answers stay accurate, cited, and traceable. 

Prove It Works 
** Build and run eval harnesses. If a system can't pass its score, it doesn't ship. That's the rule. 

Stay Current
** The field moves weekly. Trach what's new, test it honestly and bring what works into real projects.

Non-negotiable — every candidate must bring all of these

Communication Clarity

Team-First Mindset

Ownership & Accountability

Active Listening

Technical Skills:
Python Fundamentals

Logic & Problem Solving

APIs & Data Basics

Genuine AI Curiosity
** You've used LLMs beyond chat. A side project, a script, a hobby build. Show us.
