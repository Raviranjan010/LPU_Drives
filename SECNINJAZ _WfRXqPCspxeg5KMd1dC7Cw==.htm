Job Profile Details:

Position: QA Intern

Key Responsibilities:
** Understand project requirements, business workflows, and functional specifications
** Prepare and execute functional test cases based on requirements
** Identify, document, and track software defects using bug-tracking tools
** Perform regression, smoke, and sanity testing
** Assist in Accessibility Testing based on WCAG 2.1 guidelines
** Verify application compliance using accessibility tools such as WAVE, axe DevTools, Lighthouse, and screen readers
** Participate in test planning, test execution, and defect verification
** Support QA documentation, including test cases, test reports, and checklists
** Assist the team in understanding and following STQC testing processes and documentation requirements
** Collaborate with developers, business analysts, and senior QA engineers to resolve issues
** Continuously learn new testing techniques, standards, and industry best practices.

Required Skills:
** Basic understanding of automation testing using Selenium or Playwright.
** Basic programming knowledge in Python for test automation and scripting.
** Basic understanding of Software Testing Life Cycle (STLC) and Software Development Life Cycle (SDLC)
** Knowledge of Functional Testing concepts
** Basic understanding of Accessibility Testing and WCAG guidelines
** Familiarity with HTML, CSS, and basic web technologies
** Strong analytical and problem-solving skills
** Good written and verbal communication skills
** Ability to learn quickly and work effectively in a team

Preferred Skills:
** Knowledge of STQC testing standards and certification processes
** Familiarity with accessibility testing tools (WAVE, axe DevTools, Lighthouse, NVDA, JAWS, VoiceOver)
** Basic knowledge of API testing using Postman
** Basic understanding of SQL and databases
** Exposure to defect tracking tools such as Jira or GitLab.
