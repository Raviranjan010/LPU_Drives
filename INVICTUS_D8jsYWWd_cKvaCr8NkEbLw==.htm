Job Profile Details:
Designation: Software Engineering Intern 

The Role:
** We are looking for a Software Engineering Intern (Full Stack) who wants hands-on experience across our web dashboard, APIs, and (with mentorship) our mobile field app.
** You will ship well-scoped changes with code review — bugs, features, SQL/data checks, and GitHub pull requests — while learning how a multi-tenant SaaS product is built and operated.

What you will work on:
** Web dashboard — features and fixes on our Next.js operations dashboard: trips, maps, forms, workflows, reports, and role-based access
** Backend APIs — REST endpoints and MySQL work on our Node.js / Express API: auth, trips, forms, workflows, and reports
** Mobile exposure — occasional React Native work (trip/map flows, push notifications, location) with a mentor
** AI implementation — help build and improve AI-powered features: on-device vision models (TensorFlow.js), camera-based safety detection, video frame analysis, and backend pipelines that support risk assessment workflows
** Day-to-day engineering — reading existing code, debugging, writing clear PRs, and improving reliability for enterprise users.

Tech you will use
Web
** Next.js, React, Chakra UI, Redux, Axios
** Mapbox / Google Maps, ApexCharts

Backend
** Node.js, Express, MySQL, JWT, Joi
** AWS, Firebase Admin, cron jobs

Mobile (exposure)
** React Native, Mapbox, Firebase (FCM / Crashlytics), background geolocation

AI / computer vision
** TensorFlow.js and on-device ML models (e.g. COCO-SSD, MobileNet)
** Camera and face-detection integrations for driver safety monitoring
** Video processing and frame analysis for Journey Risk Assessment (JRA) and RSA workflows
** AI-assisted development tools as part of how the team builds and ships

Practices
** Git / GitHub, REST APIs
** Multi-tenant org data
** Maps and geo (zones, routes, trip tracking)

Requirements
** Currently pursuing (or recently completed) a degree in Computer Science, Information Technology, or a related field
** Solid JavaScript and React knowledge.
** Basic understanding of React Native.
** Understanding of REST APIs and basic SQL.
** Familiarity with Git and debugging (browser DevTools / application logs).

Nice to Have
** Coursework or personal projects with Node/Express, Next.js, or React Native.
** Experience with maps (Mapbox / Google Maps), geolocation, or any GPS / geo project.
** Exposure to Redux, Chakra UI, Firebase, or AWS S3.
** Coursework or projects in AI, ML, or computer vision (TensorFlow, OpenCV, or similar).
** Interest in applying AI to real-world safety, fleet, or field-operations problems.
** Interest in field operations, fleet, or road-safety products.

What we look for
** Curiosity and willingness to dig into unfamiliar code — including AI and vision features.
** Ownership of small tickets end-to-end.
** Habit of reading existing patterns before rewriting.
** Comfort working in a small team that ships to real enterprise users.
** Interest in learning how AI is applied in production, not just in demos or coursework.
